Font Family (Tipo de Letra)

Define la familia tipográfica o fuente que se utilizará para mostrar el texto. CSS ofrece familias genéricas como serif, sans-serif, monospace, cursive y fantasy.

Roboto Slab font-family: 'Roboto Slab', serif;
Fuente con remates (serif), ideal para textos largos y lectura en papel.
La tipografía es el arte y técnica del manejo y selección de tipos.
Oswald font-family: 'Oswald', sans-serif;
Fuente sin remates (sans-serif), moderna, limpia y de alta legibilidad.
La tipografía es el arte y técnica del manejo y selección de tipos.
Dancing Script font-family: 'Dancing Script', cursive;
Fuente cursiva, simula la escritura manual, ideal para títulos elegantes.
La tipografía es el arte y técnica del manejo y selección de tipos.
Courier New font-family: 'Courier New', monospace;
Fuente monoespaciada (monospace), todos los caracteres ocupan el mismo ancho.
La tipografía es el arte y técnica del manejo y selección de tipos.

Font Size (Tamaño de Letra)

Controla el tamaño del texto. Se puede usar px (píxeles), em (relativo al padre), rem (relativo a la raíz), % (porcentaje) y vw (viewport width).

Tamaño pequeño font-size: 12px;
Útil para textos secundarios, notas al pie o información complementaria.
Texto con tamaño de 12 píxeles
Tamaño normal font-size: 1rem (16px);
Tamaño estándar para textos de lectura, ideal para párrafos.
Texto con tamaño normal de 1 rem (16px)
Tamaño grande font-size: 1.5rem (24px);
Ideal para subtítulos o textos destacados.
Texto con tamaño grande de 1.5 rem
Tamaño muy grande font-size: 2.5rem (40px);
Perfecto para títulos principales o encabezados.
Texto muy grande
Tamaño responsive font-size: 5vw;
El tamaño se adapta al ancho de la pantalla (5% del viewport).
Texto responsive (cambia con la pantalla)

Text Align (Posiciones / Alineación)

Controla la alineación horizontal del texto dentro de su contenedor. Los valores principales son: left, center, right y justify.

Alineación izquierda text-align: left;
Alineación por defecto, el texto se ajusta al borde izquierdo.
Este texto está alineado a la izquierda. Es la forma más común de leer.
Alineación centrada text-align: center;
Ideal para títulos, encabezados o elementos destacados.
Este texto está centrado horizontalmente.
Alineación derecha text-align: right;
Útil para fechas, números o elementos en el lateral derecho.
Este texto está alineado a la derecha.
Alineación justificada text-align: justify;
Distribuye el texto uniformemente entre los márgenes, común en libros.
Este texto está justificado, lo que significa que se distribuye uniformemente entre los márgenes izquierdo y derecho.

Font Weight & Style (Grosor y Estilo)

font-weight controla el grosor del texto (normal, bold, 100-900). font-style define si el texto es normal, cursiva u oblicuo.

Light font-weight: 300;
Texto delgado o ligero.
Este texto es light weight
Regular font-weight: 500;
Grosor normal o estándar.
Este texto es regular weight
Bold font-weight: 700;
Texto en negrita, ideal para resaltar información.
Este texto es bold weight
Cursiva font-style: italic;
Texto inclinado, usado para citas o énfasis.
Este texto está en cursiva
