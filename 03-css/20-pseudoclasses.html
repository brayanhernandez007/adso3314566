20 - Pseudoclasses

Estados especiales aplicados a elementos con CSS.

:hover

Se activa cuando el cursor pasa sobre el elemento.

Hover :hover
Cambia el color y tamaño al pasar el mouse.

:focus

Se activa cuando el input recibe enfoque.

Focus :focus
Cambia el borde al seleccionar el input.

:first-child y :last-child

Selecciona el primer o último elemento de un grupo.

Child Selectors :first-child
El primer y último elemento cambian de color.
