Text Align

Permite alinear el texto horizontalmente.

Left text-align: left;
Alinea el texto a la izquierda.
Este texto está alineado a la izquierda.
Center text-align: center;
Centra el texto horizontalmente.
Este texto está centrado.
Right text-align: right;
Alinea el texto a la derecha.
Este texto está alineado a la derecha.

Text Decoration

Agrega líneas decorativas al texto.

Underline text-decoration: underline;
Subraya el texto.
Texto subrayado
Line Through text-decoration: line-through;
Tacha el texto.
Texto tachado

Text Transform

Modifica las mayúsculas y minúsculas del texto.

Uppercase text-transform: uppercase;
Convierte el texto en mayúsculas.
texto en mayúsculas
Capitalize text-transform: capitalize;
Convierte la primera letra en mayúscula.
texto con capitalize aplicado
