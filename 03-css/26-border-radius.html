26 - Border Radius

Property defines the radius of the element's corners.

Border-Radius: 50%

Convierte un cuadrado en un círculo perfecto.

border-radius: 50%;
Crea un círculo perfecto

Border-Radius: 50px 0 14px

Esquinas superior izquierda, superior derecha, inferior derecha, inferior izquierda.

border-radius: 50px 0 14px;
(top-left) (top-right & bottom-left) (bottom-right)

Border-Radius: 100px 0 0 150px

Valores individuales para cada esquina.

border-radius: 100px 0 0 150px;
(top-left: 100px) (top-right: 0) (bottom-right: 0) (bottom-left: 150px)

Border-Radius: 0 0 0 100px

Solo la esquina inferior izquierda tiene radio.

border-radius: 0 0 0 100px;
Solo esquina inferior izquierda redondeada

Border-Radius: 1px 40px 500px 1000px

Valores extremos crean formas únicas.

border-radius: 1px 40px 500px 1000px;
Valores progresivos que crean una forma asimétrica

Sintaxis de Border Radius

La propiedad border-radius puede tener de 1 a 4 valores.

1 valor: border-radius: 10px; → todas las esquinas iguales

2 valores: border-radius: 10px 20px; → (top-left/bottom-right) (top-right/bottom-left)

3 valores: border-radius: 10px 20px 30px; → (top-left) (top-right/bottom-left) (bottom-right)

4 valores: border-radius: 10px 20px 30px 40px; → (top-left) (top-right) (bottom-right) (bottom-left)

Unidades permitidas: px, em, rem, %

Porcentaje: 50% crea un círculo/elipse perfecto
