21 - Lists

Propiedades para personalizar listas en CSS.

List Style Type

Cambia el tipo de viñeta o numeración.

Disc list-style-type: disc;
Viñetas circulares rellenas.

  • CSS
  • JavaScript
Circle list-style-type: circle;
Viñetas circulares vacías.

Square list-style-type: square;
Viñetas cuadradas.

List Style Position

Controla la posición de las viñetas.

Inside list-style-position: inside;
Las viñetas quedan dentro del contenedor.

List Style None

Elimina las viñetas de la lista.

None list-style: none;
